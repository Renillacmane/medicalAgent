# Implementation plan history

This folder holds **archived** copies of `ralph/IMPLEMENTATION_PLAN.md` with readable timestamps. Use it to compare past plans or restore a previous state.

- **Naming**: `IMPLEMENTATION_PLAN_YYYY-MM-DD.md` (e.g. `IMPLEMENTATION_PLAN_2026-03-04.md`).
- **Current plan**: Always use `ralph/IMPLEMENTATION_PLAN.md` at the ralph folder root; the planning and build agents read/write that file.
- **When to archive**: Before a major planning run or when you want a snapshot (e.g. end of a cycle or before changing strategy).

Files in this folder are read-only references; do not point the loop at them.
